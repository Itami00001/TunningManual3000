# Assets Directory

This directory contains static assets for the TuningManual3000 application.

## Structure

```
assets/
└── images/
    ├── cars/           # Car images (e.g., nissan-silvia-s14.png)
    └── parts/          # Part images (e.g., sr20det.png)
```

## Image Guidelines

- **Format**: PNG or WebP preferred
- **Size**: Recommended 800x500px for cars, 400x400px for parts
- **Naming**: Use slug format (lowercase, hyphens)

## Placeholder

If no image is available, the application will display an emoji placeholder.
